# Recorded results

One folder per run, as written by the run, with `provenance.json` (script version and SHA-256, SHA-256 of every input,
configuration) and `summary.txt` (consistency check against the detection pipeline and outcome counts).
[`../docs/results.md`](../docs/results.md) explains every folder and column; [`INPUT_HASHES.md`](INPUT_HASHES.md)
lists the input files of every run.

[`post_hoc/`](post_hoc/) holds analyses added after the parameters were fixed; they are labelled as post-hoc
throughout.
