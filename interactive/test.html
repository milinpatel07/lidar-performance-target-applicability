Applicability test calculator

The applicability test uses a threshold τ selected in the condition of selection unchanged in the condition of use. From n independent units of the test part of the condition of use, with mean per-unit share Â of false acceptances among the accepted detections, it computes the interval [L, U] of the false acceptance proportion (FAP) at confidence 1 − δ (δ/2 on each side) and decides: applicable if U ≤ α, not applicable if L > α, not determined otherwise. The same Hoeffding-Bentkus (HB) p-value decides whether a candidate threshold passes the selection at δ. A unit is a frame or a recorded sequence; the p-value and the interval require the units to be independent.

Load a recorded row

The list holds the rows of the sequence-level evaluation (division by recorded sequence, unit recorded sequence) from results/m7_scene_split/m7_scene_split.csv (variant scene_scene_unit) and results/m8_kitti_drive_split/B_dataset_drive.csv (hb_unit drive) for which a threshold was selected, read from explorer/data/outcomes.json. For these rows the files record both the mean per-sequence value Â and the number of test sequences n, and the HB interval depends on the per-unit values only through these two numbers, so L and U can be recomputed here from the recorded values. Rows of the frame-level evaluation are not offered: the files of the KITTI distance and of the change of dataset and detector (results/m6_protocol_seeds_weather) do not record the number of test frames used in the interval. The selection p-value of a recorded row cannot be recomputed, because the files do not record the mean per-unit share of the selection part.

How it is computed

Code: interactive/stats.js, a port of hb_pvalue, hb_upper, hb_lower and n_required in analysis/m1_range_kitti.py. tools/test_stats_js.py compares the two on seeded random cases and on the recorded rows.

HB p-value for the null hypothesis FAP > α, from n independent per-unit values in [0, 1] with mean Â (sum S = nÂ):

p = min{ exp(−n·h(min(Â, α), α)),  e·P(Bin(n, α) ≤ ⌈nÂ⌉) }

h(v, w) = v·ln(v/w) + (1 − v)·ln((1 − v)/(1 − w)),  0·ln 0 = 0

with a binomial random variable Bin(n, α) and Euler's number e; p = 1 if Â ≥ α. A candidate threshold passes the selection if p ≤ δ.

Interval. U is the smallest α at which p ≤ δ/2 (found by bisection, 50 steps). L is one minus the same bound computed from the values 1 − af, that is from the sum n − S. [L, U] holds the FAP with confidence 1 − δ.

Minimum number of units (Eq. 5 of the paper, the zero-failure bound):

n ≥ ln δ′ / ln(1 − α),  δ′ = δ for selecting, δ′ = δ/2 for testing a threshold.

The table also shows the smallest n at which n units without a false acceptance pass the HB test itself (n_required). The lowest limit that n units without a false acceptance can show to be met is the inverse of Eq. 5, 1 − δ′1/n. Eq. 5 is necessary, not sufficient: any unit with a false acceptance raises the number of units needed.

  • Terms as in the paper and the glossary. Target limits are 10⁻², 10⁻³ and 10⁻⁴; 0.05† and 0.1† are exploratory limits, which define no performance target.
  • An applicable outcome is informative only together with its retention, the share of correct detections that the threshold accepts; a threshold that accepts almost nothing meets any limit.
