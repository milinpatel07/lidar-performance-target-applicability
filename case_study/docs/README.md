# Documentation of the case study

Paths on these pages are relative to `case_study/`. The test itself is explained in
[`../../docs/concept.md`](../../docs/concept.md); terms are defined in [`../../docs/glossary.md`](../../docs/glossary.md).

| page | what it holds |
|---|---|
| [`method.md`](method.md) | what the experiment scripts in `experiments/` compute, step by step |
| [`results.md`](results.md) | every folder and column of `results/`, the outcome table over the five splits, and an index from each section, table and figure of the paper to the files that hold its values |
| [`paper_map.md`](paper_map.md) | every checked number of the paper with its source file and the result of the check (written by `checks/check_paper_numbers.py`) |
| [`data.md`](data.md) | datasets, splits, detector outputs and their licences |
| [`provenance.md`](provenance.md) | toolbox version, detector configurations, training runs and the checkpoints that inference loaded |
| [`reproduce.md`](reproduce.md) | the commands for the checks, for tables and figures from the recorded results, and for the experiment runs |
| [`pipeline.md`](pipeline.md) | which script reads which file and writes which file |
| [`study_protocol/`](study_protocol/README.md) | the predictions fixed before any outcome was computed, their outcomes and every deviation |
| [`supplementary/supplementary.pdf`](supplementary/supplementary.pdf) | the supplementary material, generated from the repository files only, with a table of the source of every printed value |
