Run the test on your own detections

This page applies the applicability test to a CSV file of detections of your own detector. A threshold τc is selected on the selection part of the condition of selection c and tested unchanged on the test part of the condition of use c′. Everything is computed in this browser; the file is read locally and no data leave the computer.

1. Load detections

One row per detection, with a header. Columns: frame (frame id), sequence (recorded sequence id; optional, needed for the sequence-level evaluation and for a division by sequence), condition, part (selection or test; optional; rows marked grid are used only for the candidate thresholds), u (indicator value; a higher value means more uncertain; a detection is accepted if u ≤ τ) and correct (1 for a correct, 0 for a wrong detection). Separator: comma, semicolon or tab.

4. Outcome for c → c′

Outcome in the condition of use:

HB p-value of each candidate threshold in c (selection part)

Candidates are taken from the lowest upwards; the selected threshold is the last candidate that passes (p ≤ δ) before the first that fails. A candidate above the first failure is not selected even if it passes.

5. All ordered pairs of conditions

Rows: condition of selection c; columns: condition of use c′; the diagonal is the own-condition check. Each cell uses the candidate thresholds of its own pair, so τc can differ between the cells of one row. Select a cell to show it above.

How it is computed
  • A frame belongs to a condition if it holds a detection of the condition. For each frame, af(τ) is the share of wrong detections among the accepted detections of the condition in the frame, and 0 if the frame has no accepted detection (Eq. 2 of the paper). In the sequence-level evaluation the value of a recorded sequence is the mean of af over its frames in the condition (frames are then identified by sequence and frame id), and n counts sequences.
  • Selection: HB p-value of each candidate for the null hypothesis FAP > α on the selection part of c, fixed sequence from the lowest candidate; no threshold is selected if the lowest candidate fails.
  • Test: [L, U] of the FAP of τc on the test part of c′, each bound at δ/2; applicable if U ≤ α, not applicable if L > α, not determined otherwise. Retention: share of the correct detections of the test part of c′ that τc accepts. Own-condition check: the same test on the test part of c.
  • Candidates: numpy-style quantiles (linear interpolation) at levels 0.01 to 1.00 of u over the rows of c and c′ marked grid, or over their selection part if there is no grid row.
  • Eq. 5 of the paper: at least ln δ′ / ln(1 − α) independent units, δ′ = δ for selecting and δ/2 for testing; necessary, not sufficient.
  • The p-value and the interval require independent units drawn from one distribution per condition, and test units independent of the selection units. Frames of one recorded sequence are not independent.
