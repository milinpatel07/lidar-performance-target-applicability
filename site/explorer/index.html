Results browser

Every recorded outcome of the KITTI and nuScenes case study. Each cell of the grid is one threshold τ selected in the condition of selection so that the false acceptance proportion (FAP) stays at or below the limit α, then tested on the test part of the condition of use. The Hoeffding-Bentkus interval [L, U] of the FAP at 95 % confidence decides the outcome: applicable if U ≤ α, not applicable if L > α, not determined otherwise, and no threshold selected if the lowest candidate threshold fails in the condition of selection. Each cell shows the five splits 0 to 4.

About these data

  • All values are read from data/outcomes.json, which tools/build_explorer_data.py writes from these result files (each detail row links its file and line):
    • division by frame: results/m6_five_splits/A_kitti_range_protocol.csv (KITTI distance), results/m7_nuscenes_by_scene/m7_scene_split.csv (variant frame: nuScenes distance and weather), results/m6_five_splits/B_shift_seeds_protocol.csv (change of dataset and detector);
    • division by recorded sequence: results/m7_nuscenes_by_scene/m7_scene_split.csv (variants scene_frame_unit, scene_scene_unit), results/m8_kitti_by_drive/A_kitti_distance_drive.csv and B_dataset_drive.csv (hb_unit frame or drive);
    • post-hoc: results/post_hoc/outcomes.csv (method A or B).
  • The views use the terms of the paper (Sect. 4.3): the frame-level evaluation divides frames at random and counts frames as units; the sequence-level evaluation divides and counts recorded sequences; the third run divides by recorded sequence but counts frames, to separate the effect of the division from that of the unit. The data file keeps the labels division and unit of the result files.
  • Target limits are 10⁻², 10⁻³ and 10⁻⁴, fixed before any outcome was computed. The exploratory limits 0.05† and 0.1† were fixed at the same time to show at which limits the test reaches the outcome applicable or not applicable; they define no performance target.
  • Frames of one recorded sequence (KITTI drive, nuScenes scene) are not independent of each other, so in the frame-level evaluation and the third run the stated error probability is not guaranteed. The sequence-level evaluation treats the recorded sequence as the independent unit.
  • Post-hoc entries (Methods A and B) were added after the parameters of the study were fixed and the outcomes were known; they are not part of the predictions fixed in advance. For them, the estimate and [L, U] refer to the transformed sequence loss Y, compared with α (see results/post_hoc). They use the KITTI rule.
  • KITTI rule: wrong KITTI detections inside a DontCare region or matching a van are excluded. Without it, the KITTI rows show the files' as_run rows. The nuScenes rows are the same with or without it.
  • Far distance and rain are treated as potential triggering conditions; near distance and clear weather are not. The change of dataset and detector does not isolate a triggering condition and serves as an experimental control.
  • The detail panel of a cell draws, for each split, the interval [L, U] against the limit α and, where the file records the test units n, n against the minimum of Eq. 5 of the paper for testing, n ≥ ln(δ/2)/ln(1 − α) with δ = 0.05. The URL of the page keeps the chosen view, filters and cell, so that it can be shared.
